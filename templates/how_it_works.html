How WebTrust Works

A step-by-step overview of the passive website trust and risk assessment pipeline.

Three-Step Analysis Process

1

Enter Website URL

The user enters a target website URL or domain name. WebTrust checks the domain format, prepends standard protocol schemes if missing, and validates the URL syntax.

2

WebTrust analyzes security and trust indicators

The backend makes a passive HTTP request to check server status, TLS/SSL certificates, domain registration details, response headers (HSTS, CSP), and trust page hyperlinks (About, Privacy, Terms).

3

WebTrust displays the risk score and detailed results

The risk engine computes a 0–100 score with a transparent classification (Low, Medium, or High Risk). The user is presented with categorized findings, Matplotlib visual charts, and downloadable reports.

Detailed Technical Pipeline

1.
Passive Inspection (checker.py): Safely retrieves the HTTP headers and webpage HTML using Python requests with a 7-second timeout. It captures redirect chains, response timing, and server software banners without invasive probing.
2.
HTML & Signal Parsing: Using BeautifulSoup, WebTrust extracts outbound links, counts input forms, verifies password field security, and scans for standard trust and legal pages (Privacy Policy, Terms of Service, Contact).
3.
Heuristic Risk Engine (risk_score.py): Scores risk factors across 6 distinct categories: HTTPS & SSL, Domain & Host, URL Structure, Redirects, Web Content, and Security Headers.
0 – 29: Low Risk 30 – 65: Medium Risk 66 – 100: High Risk
4.
Server-Side Visualizations (graph.py): Generates statistical charts using Python's Matplotlib headless engine. No client-side JavaScript libraries are loaded; charts are rendered server-side as high-resolution PNG images.
5.
Report Generation: Saves persistent scan records in scan_history.json and compiles detailed downloadable reports in Plain Text (.TXT), PDF, and structured JSON formats.

About WebTrust

WebTrust is a website trust and risk analysis project developed to help users understand basic security and trust indicators of a website.

Disclaimer: This project evaluates publicly observable signals using automated heuristics. It does not claim that the system can guarantee whether a website is completely safe or malicious. Always exercise normal security caution when browsing the web.
