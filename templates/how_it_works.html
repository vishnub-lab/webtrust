How WebTrust Works

A step-by-step walkthrough of the passive trust analysis pipeline, built for students and educators.

1

User Enters Website URL

The user inputs a target URL into the web interface. WebTrust normalizes the URL (ensuring proper protocol formatting like https://) and validates the domain syntax before making any network connections.

2

Python Collects Website Information (Passive HTTP)

Using the Python requests library, WebTrust makes a standard, safe GET request with a 7-second timeout. It measures response time, observes redirects, captures the HTTP status code, and inspects server response headers.

🔒 Safety Guarantee: WebTrust never performs brute-forcing, injection, port scanning, or intrusive testing.

3

Python Checks Trust Signals

Using BeautifulSoup and URL parsing routines:

  • URL Heuristics: Checks length, IP addresses vs domains, excessive hyphens, and suspicious keywords.
  • Content Heuristics: Detects urgency language, fake-support prompts, login-heavy pages, cross-domain form actions, and possible brand/domain mismatches.
  • Content Analysis: Counts hyperlinks, form elements, and presence of password fields.
  • Trust Pages: Searches for links pointing to Privacy Policy, About Us, Terms of Service, and Contact info.
  • Security Headers: Audits defensive headers like HSTS, CSP, X-Frame-Options, and X-Content-Type-Options.
4

Python Calculates Risk Score (0 – 100)

In risk_score.py, a transparent rule engine aggregates risk points. The score ranges from 0 (very few risk indicators) to 100 (many risk indicators):

0 – 29: Likely Trustworthy
30 – 65: Needs Caution
66 – 100: High Risk Indicators
5

Python Generates Matplotlib Graphs

Server-side Python code in graph.py uses Matplotlib (headless Agg backend) to create three high-resolution charts:

  • Graph 1 – Risk Breakdown: A horizontal bar chart of category risk points.
  • Graph 2 – Trust Signals: A donut/pie chart of Positive vs Warning vs Risk signals.
  • Graph 3 – Scan History: A line chart tracking risk scores over past scans.

* Zero client-side JavaScript is used; images are rendered directly on the server as PNG files.

6

Flask Displays Report & Generates Download

The Flask controller renders result.html containing the comprehensive visual dashboard, saves the scan entry to scan_history.json, and writes a detailed text report file in reports/ for the user to download.
